# 领域入门与前沿地图

enter/frontier/directions先使用 [field-discovery](field-discovery.md) 的discover流程；一页field-judgment先于候选。年表必须解释路线演进原因/条件/残余瓶颈，不能只按年份列论文。给定机制另记待反驳先验，不把领域发现缩成特定机制审查。

1. 在 `research-brief.md` 写领域边界、目标（学习/论文/应用）、截止日期（含时区）、先验能力、数据权限、算力、时间预算。未知资源标 `unknown`；不阻断阅读，不能暗推资源充足。将宽泛领域切成任务、场景、评价标准；列领域已有术语和排除项。
   检索前填 brief 的“查询分析”：判断问题形状并拆子问题。直接型只做该子问题需要的层，不强走全部层；横向型按子问题分别覆盖，每个子问题仍保留 negative_results 与 countersearch；纵深型按视角组织。searches 记录用可选 `subq` 标注所属子问题，便于看出“哪个子问题缺哪层”。
2. 分层检索并记查询、检索日期、入口、时间范围和失败/缺口。查询先宽后窄：先用短而宽的查询和综述收集术语变体回填 brief，再逐步收窄；不要一开始就写长而具体、命中极少的查询：
   - 综述/教程：先形成概念树，确认作者检索范围和截止日期；综述不是所有结论的原始证据。
   - 奠基/经典：沿综述引用回溯，记录问题起源、核心假设、评价变化；不只搜索今年论文。
   - 强基线：找当前同任务、同预算、同数据设定的强方法，包括简单方法和复现报告。
   - 近期前沿：前向引用、会议/期刊、预印本，区别公开版本、accepted 与正式发表。固定信息截止日期。
   - 争议/负结果：搜 failure、limitation、negative result、replication、correction/retraction 及同义词；记录搜不到的缺口，不能把没有结果当作没有反例。

   **发现，而不只是核对。** 按标题、作者、会议找一篇已知论文是 known_item，只能核对已有清单（包括项目里原有的文献表）。地图要靠 exploratory 检索（按问题、术语变体、邻近领域叫法）和 snowball（从至少 2 篇核心论文做前后向引用）扩出去；searches 用可选 `intent` 标明。默认至少 5 次 exploratory，snowball 不为零。预算是上限也是下限：关键子问题仍 unresolved 而预算未用完时继续检索，不提前交付。
   **先广后深。** 核心论文和决定性近邻读到正文（方法、实验设置、局限）之后，才在外围材料（专利逐条权利要求、产品页、二手转述）上花精读预算。
3. 建 `landscape.md`：每行问题 → 方法 → 假设 → 支持/反证 claim ID@rev → 瓶颈 → 适用条件。区分论文声称、自己复现、推测。结论不能越过实际阅读深度。关键数字对照 PDF 与原始源码；清洗文本只是阅读辅助。
4. 阅读路径按概念依赖排序，写读这篇为了回答什么。每篇版本在 `research/papers.jsonl`，其证据在 claims。记录页码/图表、split、样本量、指标、资源、负例，缺失项写未知，不补造数字。
   面向新手首次展开缩写和指标口径；作者版/会议最终版是阅读工件，录用/发表是作品状态，分别核对官方身份页、出版页与关联版本。存在冲突就列依据和待核，不以arXiv URL或无Comments断言未发表。
5. 趋势至少有多项独立工作、跨时间节点、可比较的指标或设置变化；同文 v1/v2、新闻转述、综述转引不算独立证据。无这些条件时写“线索/待核实”，不宣称趋势。年代分层的经典与近期都要有出处和定位；不能以数量替代覆盖质量。
6. 用户需要方向时，从地图列候选假设；到 [opportunity-review.md](opportunity-review.md) 查最近似工作、资源和最小实验，再进入复现。仅入门在判断/阅读路线交付，不展开候选。不存在证据支持的空白不等于创新机会。

增量搜索先读现有地图及 JSONL，只补截止日期以后或已知缺口，追加新证据而非抹去历史。每个最终判断附检索范围、反证、置信度与未解决问题。

## 第二版：可审查的检索覆盖契约

每个查询追加 `research/searches.jsonl`，不能只留下“已查文献”摘要。记录：source capability（名称、访问状态、支持哪些元数据/全文/分页/总数能力、限制）、query、layer、searched_at、ISO date time_range、returned_count、total_hits（未知显式 null）、pagination 状态/已取页数、status、coverage_claim、预算上限/已花费/单位。
完整是对声明的有界查询过程完成，不等于领域穷尽。未知总数或分页截断不可宣称 exhaustive；来源不可用、访问失败或未完成时 coverage_claim=unknown。零命中与访问失败分开，零命中可如实记录，但不是创新证明。来源能力不足可降级为摘要/局部覆盖，标明哪些问题仍不能判断，不要求商业 API 或凭据。

保持 review / foundational / strong_baseline / recent / negative_results 基础覆盖，再做 countersearch。ready 的 V2 卡须引用各层实际有命中的完成记录；层次缺口仍可交付 candidate/blocked。没有负结果命中只代表该查询缺口，不能伪造论文凑齐 ready。可能使用局部有界来源，必须报告限制。

主张的 material_access 与 paper reading_depth 独立：未检查、不可以访问、提取失败不能混称全文已读。locator_reliability 分 page/structure/source_only；完整阅读也可能只有来源级定位。可靠度是声明的引用粒度，页码正确性仍需审查。

## 关键矛盾与 why-now

在 tensions 记录冲突结果、异常、反复失败条件或获取/观测/测量瓶颈；固定 evidence 引用、替代解释、重要性、why_now（工具/数据/条件发生何种变化）及可进攻路径。重大但目前无路径的矛盾标 parked 并写原因。不要把问题重要性等同可做性，不硬凑三个方向。

从地图出发列竞争解释，包括简单/强基线已经足够的可能性。每次下一轮检索先说明：什么信息会改变继续/放弃决定、critical_unknown、最可能推翻首选方向的证据、查询预算。先补基础覆盖，再检验关键风险；避免只顺着自己的方法找支持。预算耗尽标 unresolved，保留缺口到交接。

## A/B/C 的可读交付顺序

A 核心与最新文章不是按引用数抓榜：先按任务相关性、概念影响、方法代表性、证据质量、强基线价值和近期突破/反例价值筛选，明确为什么值得读、先后概念依赖与截止日期。
B 汇总领域主要问题、正在走的方法路线、假设与约束、支持和反证、突破线索与瓶颈；多篇跨时间的可比证据不足时把趋势写成待验证线索。
C 仅在用户需要选题时，从B的矛盾与新条件提出少量方向，每个用最近似工作差异、资源关卡、最小判别计划、主要风险和停止条件支撑。最后附未覆盖层次、访问限制和下一关键检索，不用日志字段淹没方向判断。
